# 3D 实现与取景

## 场景

书根下放书脊、左右叶，叶下放封皮、纸层、印刷纹理、照片和模型。折页绕书脊，内容随所属叶移动。哑光材质、柔和主光、半球光、接触阴影体现纸张厚度。

照片平面按真实长宽比创建，纹理为 sRGB。纸、框、照片、胶带给不同且稳定的深度，不用同平面透明排序解决闪烁。按需要设置透明材质 depthWrite，不全局禁用深度测试。几何分层优先，polygonOffset 只处理剩余共面问题。

不同地标突出可辨认结构：白宫两层主楼、侧翼、门廊和旗杆；林肯纪念堂台阶、柱列、平顶与坐像；国会圆顶和两翼。其他目的地按实际建筑设计，不能简单换标签。

## 让书大且完整

1. 画布用完整视口，测量顶部标题、底部目录、侧栏实际占位，得到安全矩形。
2. 收集可见各 mesh 的局部 boundingBox 八角并乘 matrixWorld。不要先合并全书世界轴对齐包围盒，它在斜视角产生大量虚空，让书太小。
3. 相机局部坐标点 p 满足 `d >= p.z + abs(p.x)/tanX`、`d >= p.z + abs(p.y)/tanY`。assets/framing.mjs 实现该公式。
4. 垂直半视场角正切为 `tan(fov/2)/zoom`，乘安全区高度占比得 tanY，乘 aspect 与安全区宽度占比得 tanX，留 2%–6% 余量。
5. 相机先 lookAt(target) 并更新矩阵，再取 quaternion。setViewOffset 把投影中心放在安全区中心。坐标按 canvas 实际大小与 DOM 偏移换算，不能假定 canvas 从 (0,0) 开始。
6. 翻页时更新变形包围盒，结束后重新收紧镜头，不能因中途竖起纸张永久退远。
7. 视口改变、开合和照片查看结束重新拟合；窄屏切宽屏清除旧的过大 minDistance。近远裁切面容纳实际深度，照片查看使用独立拟合规则。

## 动画与性能

相机、开合、翻页用具名动画通道，新操作取消对应旧动画。拖动开始取消相机自动 tween。按时间推进，不按帧计数。缓存页面、纹理和纸纹；书页用清晰缩略图，点开才载大图，可预热邻页。透明动画使用独立材质，避免一张淡出导致其他页消失。pixelRatio 可限制为 2，阴影按变化更新，变形后重算法线和包围体。

数学检查投影角点后仍要看截图：常规桌面、较矮宽屏、窄屏；主体够大、标题不压书、建筑不遮照片。在允许的完整转动范围检查闪烁和排序。所有分配照片能在页面与查看器找到。
