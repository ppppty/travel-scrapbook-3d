# 视觉与交互默认方案

## 美术

印象派花园、奶油纸张、鼠尾草绿、灰粉与浅紫。油画感用于环境和装帧，照片保持真实色彩。参考色：纸 #fff6df、封面 #b7a3b5、叶片 #90a17d、灰粉 #c8a2b4、水 #b5d0cb。正文有足够对比，不能浅到难读。

中英搭配、细衬线、适度字距。站名、TRAVEL JOURNAL 和日期在视口内居中，不受侧边工具宽度影响。页内标题和外部场景标题不能压在同一位置。纸纹、细线、胶带和编号少量使用，让照片成为主体。

## 按数量排版

| 数量 | 构图起点 |
| --- | --- |
| 1 | 单张大照片，对页展示模型；不复制照片凑拼贴，不需要该景点独立相册 |
| 2–3 | 主副图形成节奏或双页对照，保留各自长宽比 |
| 4–6 | 主图加不同尺度小组，或横向叙事带，预留模型区 |
| 7–10 | 双页分组和明确主图，不能缩成不可看的邮票 |
| 更多 | 增加同一景点的连续跨页，目录标页数 |

左右页可对调，模型随构图移动。变化来自尺度、位置、留白与阅读节奏，不靠歪斜、裁切和杂乱堆叠。新增照片重新安排整页，不只塞进角落。人物/风景根据实际图片内容判断，不假定所有人物照都做主图。

## 交互

- 默认合上，点击封面或打开按钮可展开。
- 可旋转、有限度缩放、复位视角；相机不穿书页。
- 照片查看完整原图，可前后切换、关闭、Escape 返回原场景。
- 地标与书页联动弹起，可通过低调按钮重播。
- 景点目录和前后翻页均可操作，连续点击不能卡死。
- 合上、全部照片、复位工具放侧边或独立区域，不盖住书。
- 拖动提示放帮助入口，hover 功能有触控替代。
- 尊重 prefers-reduced-motion，减少环境漂浮与过渡，保持状态清楚。

不默认加照片袋、漂浮照片堆、写作输入框或重复标语。

## 动效

时长起点：封面 1.3 秒、翻页 1.2–1.3 秒、复位 0.85 秒、照片显现 0.6 秒、查看 0.3–0.5 秒。根据实际性能调整。

顺序为模型收拢、纸张翻转、内容替换、模型展开、照片依次显现。曲线可用 `6t^5 - 15t^4 + 10t^3`，端点速度/加速度为零。照片轻抬和缩放，不旋转。操作有可预期的排队或取消机制。
