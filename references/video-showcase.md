# 网站展示视频

真实演示：封面 → 打开 → 旋转 → 翻页 → 放大照片 → 合上。不要用生成视频替代实际功能，也不把截图幻灯片称为实录。

## 画幅与节奏

沿用已确认偏好，默认无音乐、无旁白，不重复确认。不自动加字幕、水印。5–7 个场景通常 35–50 秒，照片放大停 2–3 秒。

小红书用途不等于必须竖屏。横向打开的书优先采用能完整容纳网站的画幅，例如 1600×1000。用户明确要竖屏或网站已适配时才用 1080×1920，不能裁掉书来凑比例。参考链接先通过可用浏览器读取，登录受限时说明没有看见的内容，不臆测视频。

## 录制

先查实际可调用的录屏/视频工具。没有工具就本地录制，不把工具缺失误报成用户权限不足。不要自动上传私人照片给外部视频服务。

在网站副本或独立 capture 页录制，演示 API 与录制面板不进入正式网站。可按源码给副本增加 open、close、chapter、photo、orbit、ready、busy 接口，由录制页自身脚本调用。遵守浏览器工具约束，不用只读 evaluate 注入操作；通过允许的点击启动演示页。

WebGL 与 DOM 合成：

1. 创建录制标签后设置 viewport，再 reload。新建标签可能不继承先前设置。
2. 等字体、背景、缩略图与 shader 准备好，先导出预览检查尺寸。
3. 副本启用 preserveDrawingBuffer，或在每次 renderer.render 后立即绘制到录制 canvas；正式网站不必开启。
4. 标题和工具可用本地、具备许可的 html2canvas 等工具分别渲染、按状态缓存。不要只截整个 body：固定全屏布局的 body 可能高为零，导致 UI 丢失。
5. 背景、WebGL、UI 按同一 DOM 坐标系合成，缩放一致；不能只放大背景，让网页缩在左上角。
6. canvas.captureStream(30)，MediaRecorder 用 isTypeSupported 检测编码。时间线等 busy 结束，把实际停顿计入总时长。
7. 可加轻量操作指示点，位置从实际 DOM 或 3D 投影获得，必须与真实动作对应。
8. Blob 存本地；保存服务器仅监听 loopback，固定输出目录、限制大小、不接受任意文件路径。PNG 预览和 WebM 用不同端点及扩展名。

缓存每页、合上、照片查看的 UI。旋转只演示轻柔弧线，翻页后留时间看清，人物不裁切。

## 导出与验收

优先已有 ffmpeg；缺少可在工作目录安装 imageio-ffmpeg 等依赖，不把机器路径和巨大二进制打包进技能。参数示例，路径按执行环境正确转义：

```sh
ffmpeg -i recording.webm -an -vf fps=30,format=yuv420p -c:v libx264 -preset medium -crf 18 -movflags +faststart showcase.mp4
```

已有成品不无条件覆盖。低帧率实录补到 30 fps 不代表流畅，需要减轻负载重录。

检查视频流存在、无音频、尺寸和时长正确、完整解码。从封面、打开、各页、照片放大、片尾提帧检查，另看翻页/开合连续片段有无卡顿。检测黑帧与空白；联系表末尾未填满的格子不等于原视频黑屏。检查 UI、书边缘、所有图片、调试和录制按钮是否误入画面。

交付本地 MP4，说明时长、画幅和静音，使用可用的本地预览或文件打开工具。不能把中间 WebM 或预览图说成最终视频。用户说发小红书不等于授权代发。
